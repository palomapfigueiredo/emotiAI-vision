Início

Como o EmotiAI Vision observa movimentos em uma sala?

O EmotiAI Vision analisa imagens da câmera para identificar movimentos do corpo, como levantar a mão.

O sistema captura a imagem, identifica pontos do corpo, acompanha as pessoas e verifica se os braços estão levantados. Depois, reúne os resultados em métricas.

Importante: o sistema identifica movimentos visíveis. Não consegue determinar pensamentos, emoções, atenção ou aprendizado.

Não tenta descobrir quem é a pessoa
Analisa pontos do corpo, como ombros, cotovelos e punhos, sem precisar reconhecer o rosto.

Não guarda vídeos ou fotos no computador
As imagens são analisadas durante a execução, sem serem salvas como vídeos ou fotos; o programa reúne informações numéricas.

Os códigos de acompanhamento são temporários
Códigos como track_1 e track_2 ajudam a acompanhar movimentos durante a execução. Não identificam pessoas e são temporários.

O que significam os números?

  • Pessoas agora: quantas pessoas o sistema conseguiu detectar neste momento.
  • Braços levantados: quantas pessoas estão com um ou mais braços reconhecidos como levantados.
  • Participação (10 s): um resumo calculado para uma janela de 10 segundos, de acordo com as regras do projeto. Isso não mede interesse, aprendizado ou atenção.

Como o sistema funciona

O caminho da imagem: oito etapas

  1. Captura: a câmera entrega uma imagem ao programa.
  2. Detecção de pose: o sistema procura pontos do corpo, como ombros, cotovelos e punhos.
  3. Rastreamento: o programa tenta descobrir quais pontos de uma imagem correspondem à mesma pessoa na imagem seguinte.
  4. Análise de postura: o programa verifica se os pontos indicam que um braço está levantado.
  5. Eventos: quando algo muda, como um braço subir ou descer, o sistema registra essa mudança.
  6. Resumo das métricas: depois de um intervalo, o programa junta os registros e calcula números.
  7. Visualização de depuração: durante os testes, o programa pode desenhar os pontos e as linhas sobre a imagem.
  8. Loop principal: é a parte que organiza a ordem das tarefas e faz o processo se repetir.

Passo 1 — Captura de vídeo

1. A câmera entrega a imagem

Arquivo: camera/capture.py

A câmera captura imagens chamadas frames, que são analisadas em sequência.

A classe CameraCapture acessa a câmera e configura resolução, frequência de análise e rotação.

Passo 2 — Detecção de pose

2. O sistema procura pontos do corpo

Arquivo: detection/pose_detector.py

Agora que a imagem chegou, o sistema precisa encontrar partes do corpo. Para isso, o projeto usa o MediaPipe Pose Landmarker, uma ferramenta que estima pontos do corpo em uma imagem.

Esses pontos são chamados de landmarks. Entre eles estão os ombros, os cotovelos, os punhos, os quadris e pontos das pernas. O modelo usado pelo projeto pode identificar até 33 pontos para cada pose detectada.

Passo 3 — Rastreamento

3. Como o sistema acompanha a mesma pessoa?

Arquivo: tracking/tracker.py

Imagine que duas pessoas estejam na frente da câmera. Em uma imagem, o sistema encontra dois conjuntos de pontos. Na imagem seguinte, ele encontra os pontos novamente. Como pode tentar saber qual conjunto corresponde a cada pessoa?

É para isso que serve o rastreamento (tracking). O programa compara a posição dos pontos entre imagens consecutivas. Neste projeto, ele usa principalmente a proximidade entre os centros dos ombros.

Passo 4 — Análise de postura

4. Como o sistema percebe um braço levantado?

Arquivos: analysis/arm_detection.py e analysis/posture_detection.py

O sistema já encontrou os pontos do corpo e está tentando acompanhá-los. Agora ele verifica uma pergunta específica: a posição dos pontos indica que um braço está levantado?

Para responder, o programa compara a altura de pontos como o punho, o ombro, o cotovelo e, quando está visível, o quadril.

Passo 5 — Eventos

5. Como o sistema registra o que aconteceu?

Arquivo: events/event.py

Quando algo importante muda, o programa cria um evento. Um evento é como uma anotação curta em um caderno: registra o que aconteceu e em que momento.

Alguns exemplos de eventos que o projeto reconhece são:

  • Uma pessoa foi detectada.
  • Uma pessoa deixou de ser acompanhada.
  • O braço esquerdo foi reconhecido como levantado.
  • O braço direito foi reconhecido como levantado.
  • Os dois braços foram reconhecidos como levantados.

Cada evento pode guardar informações como o tipo de mudança, o identificador temporário da pessoa, o nível de confiança e o momento em que ocorreu.

Passo 6 — Métricas agregadas

6. De muitos acontecimentos para um resumo

Arquivos: analysis/aggregator.py e analysis/participation.py

Até aqui, o sistema recebeu muitas imagens e pode ter identificado várias mudanças. Ler cada acontecimento separadamente seria trabalhoso. Por isso, o projeto reúne os resultados em intervalos de tempo.

O tempo padrão de cada intervalo é 10 segundos. Esse período é chamado de janela de agregação.

Passo 7 — Visualização de depuração

7. Por que aparecem linhas e pontos sobre o corpo?

Arquivo: debug/renderer.py

Durante o desenvolvimento, é útil ver o que o sistema está detectando. A parte chamada DebugRenderer desenha pontos e linhas sobre a imagem da câmera.

As bolinhas indicam os pontos estimados do corpo, enquanto as linhas ligam esses pontos para formar uma espécie de esqueleto. Assim, quem está testando o projeto consegue observar se o sistema encontrou os ombros, os cotovelos e os punhos nas posições esperadas.

Passo 8 — O loop principal

8. Como tudo funciona junto?

Arquivo: main.py

Cada etapa tem uma tarefa, mas alguém precisa organizar a ordem em que elas acontecem. Esse é o trabalho do arquivo main.py, que funciona como o maestro de uma orquestra.

Ele coordena o processo:

  1. Recebe uma imagem da câmera.
  2. Envia a imagem para encontrar os pontos do corpo.
  3. Tenta acompanhar as pessoas entre as imagens.
  4. Analisa a posição dos braços.
  5. Registra as mudanças importantes.
  6. Atualiza e reúne as métricas.
  7. Mostra a visualização de depuração, se ela estiver ativada.
  8. Repete o processo enquanto o programa estiver funcionando.

Configurações do projeto

O que é possível ajustar?

Arquivo: config/settings.py

Configuração Valor padrão O que significa
frame_width / frame_height 1280 × 720 A largura e a altura solicitadas para a imagem da câmera.
rotation 180° A rotação aplicada à imagem.
max_poses 10 O número máximo de poses que o sistema tenta detectar em uma imagem.
min_landmark_confidence 0,5 O nível mínimo de confiança usado para considerar um ponto válido, conforme a implementação do projeto.
target_processing_fps 10 A quantidade aproximada de imagens que o sistema pretende analisar por segundo.
required_consecutive_frames 5 Quantos frames seguidos são exigidos para confirmar uma mudança de postura.
aggregation_window_seconds 10 segundos A duração de cada intervalo usado para montar um resumo.
tracker_max_distance 0,18 A distância máxima permitida para relacionar uma pose nova a um acompanhamento existente.
tracker_max_missed_frames 8 Quantos frames podem passar sem atualização antes de o acompanhamento ser considerado perdido.

Os valores padrão são os definidos no guia do projeto. Dependendo da câmera, da iluminação e da posição das pessoas, pode ser necessário testar configurações diferentes.

Como executar o projeto

Vamos colocar o EmotiAI Vision para funcionar?

O guia do projeto lista estas dependências:

  • mediapipe — ajuda a estimar os pontos do corpo.
  • opencv-python — ajuda a acessar e trabalhar com imagens da câmera.
  • numpy — oferece ferramentas para trabalhar com dados numéricos.

Comandos de execução

No terminal, entre na pasta do projeto e execute o programa usando o Python do ambiente virtual configurado:

cd app/computacional-vision
./venv/bin/python main.py

Se a janela de depuração estiver aberta, o guia do projeto indica que a tecla Q pode ser usada para encerrar essa janela.
